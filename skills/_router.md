# 路由协议

你负责将用户输入路由到最合适的 Skill。

## 可用 Skills

动态获取：读取 `skills/` 目录下所有不以 `_` 开头的 .md 文件。

## 路由规则

1. **动态发现**：每次路由前重新扫描 `skills/` 目录，获取最新 Skill 列表
2. **语义优先**：根据用户输入的语义，匹配最精确的 Skill
3. **覆盖度优先**：如果多个 Skill 都相关，选择能覆盖最多子任务的 Skill
4. **经验增强**：如果 Skill 的「已沉淀的经验」中有相关路由经验，优先遵循
5. **无匹配时**：不使用兜底 Skill，而是触发反思流程，将本次请求作为新 Skill 候选

## 路由后行为

确定 Skill 后：
1. 读取该 Skill 的完整 MD 定义：`skills/<skill_name>.md`
2. 按照「行为规范」执行
3. 遵守「已沉淀的经验」中的所有条目
